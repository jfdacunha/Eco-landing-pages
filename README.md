## Features

- Fully responsive (mobile-first)
- Real before/after photos from actual jobs
- Conversion-optimised with quote forms (hero + footer)
- Local SEO structured data (LocalBusiness + FAQ schema)
- Google Fonts: Syne + DM Sans
- Sticky header with click-to-call
- Floating call CTA
- No external dependencies (no frameworks, no libraries)

## Deploy to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to `main` branch, root folder
4. Your page will be live at `https://yourusername.github.io/repo-name/`
